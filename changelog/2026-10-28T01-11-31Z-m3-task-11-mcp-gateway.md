## Why

**The token is a secret.** It is generated straight into a `SecretString`,
reaches the gateway only through `GATEWAY_ACCESS_TOKEN` (never the command
line), and `Sandbox`'s `Debug` leaves it out. The live test's assertion
messages hold statuses only.

**An empty configuration is left out of the body**, as the Python SDK's
`mcp or UNSET`, while it still starts the gateway, as the SDK's
`mcp is not None` does.

**Clones share the token**, since `Sandbox` clones share everything else;
the cell is behind an `Arc`.

**The JSON is compact**, as the JS SDK writes it; Python's spacing differs,
but the gateway reads the same object either way.
