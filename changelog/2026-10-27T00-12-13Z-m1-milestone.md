# Milestone 1 (Verify v0.1): complete

Epic #4. Plan: `docs/superpowers/plans/2026-10-26-milestone-1-verify-v0.1.md`.

## What M1 established

- **Claims ledger.** `claims.json` holds 126 active claims. CLM-0085 was
  retired and replaced by CLM-0127, because the crate deliberately ignores
  `clientID`.
- **Live harness** (#5, PR #13): `just test-live hosted|sandbawks`. Each test
  gets its own drop-guarded sandbox, every sandbox is tagged with the run id,
  and a final sweep kills leftovers. Before killing, the sweep re-checks the
  run id itself (PR #23), because sandbawks ignores list filters.
- **Live tests:** one per v0.1 claim, 46 in total.
  - lifecycle: 21 (#6, PR #17);
  - commands: 13 (#7, PR #16);
  - files: 12 (#8, PR #15).
- **S4 evidence map** (#9, PR #14): 51 wire claims mapped to tests, with
  missing tests added. It refuted two claims, both fixed in M1:
  - CLM-0071: an explicit empty config value must count as unset (#18,
    PR #20);
  - CLM-0109: `close_stdin` must be refused before envd 0.5.2 (#19, PR #21).
- **Hosted E2B run** (#10, PR #22): 46/46 passed at `8cd5040`.
- **sandbawks runs** (#11, PR #23): 25/46 passed (CLM-0118 supported). All failures are sandbawks
  defects or capacity problems. The defects are filed as gfd/sandbawks
  #674-#682, plus a comment on #665.
